================================================================================
                            MODELS TESTED
================================================================================

Six classification models were trained and evaluated:

1. Logistic Regression - Baseline linear model
2. k-Nearest Neighbors (kNN) - Instance-based learning
3. Decision Tree (C5.0) - Rule-based classifier
4. Artificial Neural Network (ANN) - Multi-layer perceptron
5. Random Forest - Ensemble of decision trees
6. Support Vector Machine (SVM) - Kernel-based classifier

All models used:
- 80/20 train-test split
- 5-fold cross-validation (3-fold for SVM to optimize speed)
- Standardized features (where applicable)

================================================================================
                          CONCLUSION
================================================================================

The k-Nearest Neighbors model (k=21) is recommended as the best model for
predicting TFA offer confirmations, achieving the highest F1-Score (0.2576)
and best recall (17.23%) while maintaining competitive accuracy (88.45%).

The low recall across all models suggests that predicting who will accept
offers is inherently challenging with the current features. Consider:
- Adding more behavioral/engagement data
- Using ensemble methods
- Implementing cost-sensitive learning for the minority class

For deployment, monitor model performance over time and retrain periodically
as applicant characteristics may change.
